# The site's fonts

Self-hosted, served from `/fonts/` (scripts/build.mjs copies this folder),
and named in the head's `@font-face` rules (bundle/assets/head.html). Each
is the Latin subset of the @fontsource 5.3.0 package, under the SIL Open
Font License 1.1 (OFL.txt):

| File | Face | Copyright |
|---|---|---|
| `chakra-petch-400.woff2`, `chakra-petch-600.woff2` | Chakra Petch 400 and 600, the Cyberpunk shell's | Copyright 2018 The Chakra Petch Project Authors (https://github.com/m4rc1e/Chakra-Petch.git) |
| `inter-var.woff2` | Inter, weights 100 to 900 | Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter) |
| `jetbrains-mono-var.woff2` | JetBrains Mono, weights 100 to 800 | Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) |
