## Software you can reshape

Most programs are finished before you meet them. Ljós is built the other
way: the interface is QML text the engine can re-read while the program
runs, so saving a file patches the live window and keeps its state.
That is malleable software — tools that stay open to the people using
them, not only to the people who shipped them.

Ljós is a clean-room implementation. It reads the same `QtQuick` and
`QtQuick.Controls` modules existing QML uses, renders natively on
Linux, macOS and Windows (with Android and iOS behind the same engine),
and compiles QML to the web through ljos-web — the demos on this page
are QML, compiled and running in your browser.

## Where it runs

<CardGrid>
  <Card title="Desktop and mobile">
    One Rust engine renders through egui on Linux, macOS and Windows,
    with Android and iOS behind the same scene graph. Idle means
    0 % CPU: work is scheduled by dirty state, never polled.
  </Card>
  <Card title="The web">
    ljos-web compiles QML ahead of time to components over a DOM
    runtime — no QML interpreter ships to the browser. These pages
    embed live examples exactly that way.
  </Card>
  <Card title="From the command line">
    `ljos run Main.qml` opens a file; `--watch` re-reads it as you
    type. `ljos check --port` reports what an existing Qt Quick
    program needs to run here.
  </Card>
  <Card title="Embedded in Rust">
    Register native types, models and singletons from Rust, and let
    QML drive them. Other threads talk to the UI through one bounded
    handle.
  </Card>
</CardGrid>
