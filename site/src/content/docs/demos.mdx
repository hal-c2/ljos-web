Every demo here is a complete Ljós app from `site/src/demos/`,
compiled ahead of time by ljos-web and mounted as a lazy island:
the page reads fine with no JavaScript, each stage loads only
when it scrolls into view and pauses when it leaves, and a
browser without the feature a demo needs (WebAssembly, WebGPU or
WebGL) gets a picture of it running and the words instead. The
same files run as desktop apps with `ljos run`.

## Your own shell over a running app

The Pantry's data lives in blocks — the basket, a note, a status
contribution. Its interface is a shell, and the editor holds that
shell's source. Rewrite it and apply: your shell takes over while
the app keeps everything it held. The status line is a
contribution to a named slot, so moving the `StatusSlot` in your
shell moves the status with it. A shell that does not compile is
refused with the place and the reason, and the running one stays.
