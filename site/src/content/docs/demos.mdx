Each demo below is a small, complete QML file from `site/src/demos/`,
compiled ahead of time by ljos-web and mounted as a lazy island: the
page reads fine with no JavaScript, and the runtime only loads when a
demo scrolls into view. They were picked for what already runs well on
the web runtime — bindings, animation, timers and pointer input with
no native types.
