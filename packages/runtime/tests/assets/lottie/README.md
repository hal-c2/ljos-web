# Lottie files for tests/lottie.spec.js

`slide.json`, `blink.json`, `corner.json`, `halves.json`, `broken.json` and
`nothing.json` are written for the tests.

`hal-c2-dance.json` and `hal-c2-genie.json` are HAL-C2's avatar animations, from
[hal-c2/lottie-animation](https://github.com/hal-c2/lottie-animation) `version2/` at commit
`1a9dbdae376677f8162ad04d8db12e3ab94484d7`, byte for byte, as ljos-ui's
`features/lottie/avatars` has them. They are under the MIT licence in
[`LICENSE-hal-c2`](LICENSE-hal-c2).
